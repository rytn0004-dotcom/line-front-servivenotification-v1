# LINE 客服系統 V2.9.18

本版重點：LINE 首次綁定確認流程修正與版本對齊。

## 首次 LINE 綁定

1. 使用者輸入「綁定」或從選單進入「① LINE綁定」。
2. 身分提示固定為：
   - 家長：請回覆「家長」。
   - 老師：請回覆「老師」。
3. 家長輸入學生姓名；多位學生使用「、」分隔。
4. 老師輸入系統登記的老師姓名。
5. 確認畫面提供「確認」與「重新輸入」按鈕；直接輸入「確認」或「重新輸入」也相容。
6. 確認後依序執行：寫入「聯絡人」→「綁定暫存」改為 `BOUND` → LINE 回覆完成訊息。
7. 首次確認前最多可重新輸入 3 次。
8. 綁定完成後 3 分鐘內可用「更正綁定」修正一次；超過反悔期需走管理員審核。
9. 「課表查詢權限」預設為「否」，由管理員確認後開啟。

## 確認事件

首次綁定確認同時支援 LINE postback 與文字「確認／重新輸入」，避免按鈕事件沒有被主訊息流程處理而卡在 `WAIT_BIND_CONFIRM`。

## Google Sheet

程式使用既有「聯絡人」、「綁定暫存」、「綁定審核」等工作表；本 ZIP 不包含 Excel／Google Sheet 檔案。

## Render

Start Command：`node server.js`

部署後建議測試：
`① LINE綁定 → 家長 → 學生姓名 → 確認`

預期：
- 「聯絡人」立即新增／更新該 LINE User ID。
- 「綁定暫存」狀態變為 `BOUND`。
- LINE 收到「LINE 綁定完成！」訊息。
