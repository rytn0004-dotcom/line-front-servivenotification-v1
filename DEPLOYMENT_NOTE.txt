V2.6 多 Project Gemini 部署重點

Render 必要：
- GEMINI_API_KEY = Project A 的 Key
- GEMINI_API_KEY_B = Project B 的 Key（可選）
- GEMINI_API_KEY_C = Project C 的 Key（可選）

注意：A/B/C 必須對應不同 Google Cloud Project 才能形成真正的 Project 級備援。

API Key 只能放 Render Environment Variables，不要放 GitHub、Excel 或前端。

程式會依 Project A → B → C，並在每個 Project 內依模型順序嘗試。
成功一次立即停止；不會把同一問題全部模型都跑過一次。

若 3.8 發生 503 高需求，該 Project/模型會暫時 cooldown；使用者下一題可直接走其他可用 Project/模型。
