V2.9.13 deployment note
========================

Core fix:
- AI quota is independent of LINE binding. A user can use AI before binding; the quota row is keyed by LINE User ID and uses role fallback 「未完成綁定」.
- AI quota fields are located by header names, not hard-coded A/F/I:O/P/Q/R positions.
- AI quota read range is A:AZ to tolerate legacy/extra columns.
- Remaining count/date formulas are written to the actual columns found from headers.
- Media and image-generation quota fields are also header-based.
- Startup log prints an AI quota schema map and duplicate-header warning.
- Program fallback for 每人每日基本額度 is 5; 系統設定 remains the authoritative value.

Important:
- This version does NOT automatically delete or migrate any existing duplicate/legacy blocks in the AI額度管理 sheet.
- Before production use, inspect the schema map in Render logs once after deployment.
