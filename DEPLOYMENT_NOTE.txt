V2.9.20 deployment note

這版重點是修正「3分鐘反悔期後的重新綁定」流程。

正式規則：
1. 超過3分鐘後，使用者只能先建立「綁定審核」，不能先輸入新的學生／老師姓名。
2. 「綁定審核」中的「管理員結果」由管理員填「核准」或「拒絕」。
3. 核准後，使用者下一次 LINE 操作才進入 WAIT_ADMIN_REBIND_VALUE。
4. 使用者輸入新資料後必須再次「確認」，才更新「聯絡人」與「綁定暫存」。
5. 拒絕／取消都維持原本的 LINE 綁定。
6. 舊版若已留下 WAIT_ADMIN_REBIND_VALUE + flow=adminRebind，系統會自動補建綁定審核，避免繞過審核。

Excel 對應：
- 聯絡人：姓名、身分、學生姓名/關聯（或學生姓名/關聯（可多位））、LINE User ID、綁定狀態、最後綁定時間、通知啟用、備註、課表查詢權限。
- 綁定審核：申請時間、LINE User ID、LINE 顯示名稱、身分、目前綁定、申請變更、申請狀態、管理員結果、處理時間、備註。

Start Command：node server.js
